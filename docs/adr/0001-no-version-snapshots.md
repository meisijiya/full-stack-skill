# 技能不存版本号，只存查证流程

技能里不保存任何具体版本号，也不保存「当前最新版本」快照。技能只保存查证流程：怎么查、查什么字段、怎么判定兼容。

原因：版本快照会腐化，且预发布版常被 `latest` 标签指向。照抄快照会让用户拿到未验证的组合，而选型一旦定下再回头改代价极高。把版本判定变成每次执行的动作，比维护一张必然过期的表更可靠。

**边界**：官方文档里的版本声明（如「Zod 测试于 TypeScript v5.5 及以后」「本版本遵循语义化版本，0.x 可能有破坏性变更」）属于**约束本身**，可以引用并附来源；「某包当前 latest 是 x.y.z」这类**快照值**不保存，一律现查。模板里的版本号是占位形状，不是真实版本。

代价：每次选型都要现场跑命令，比查表慢。这是有意接受的代价。
